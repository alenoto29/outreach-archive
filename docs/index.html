This page is a static overview. The working dashboard needs a locally running Flask API and SQLite database. No hosted contact database or live dashboard is connected here.

02 / Try it

A fictional dataset is included.

The repository includes a sample CSV with invented contacts and publishers. It can be imported into a new local database to explore the dashboard without using private records.

  1. Follow the local quickstart to start Flask.
  2. Open http://127.0.0.1:8080 on the same computer.
  3. Sign in with your locally configured demo token, then import the sample CSV.
03 / Scope

Built for local use.

The app uses a Flask API, SQLite storage and a browser dashboard. It does not discover contacts or send email. The repository contains no real contacts, hosted service, or production deployment configuration.

See the security and deployment limits before considering network exposure.
